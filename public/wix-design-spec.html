B — Component Library

HeroSection Critical

Description: Full-width dark background with centered text overlay. Contains H1, subtitle, and 1–2 CTA buttons (gold primary + ghost outline).

Wix equivalent: Strip section → add Box overlay (bg: #151515, opacity 85%) → heading + paragraph + button stack

Key CSS: min-height: 70vh; background-size: cover; background-position: center; text-align: center; padding: 96px 24px

TrustTicker Important

Description: Narrow horizontal bar scrolling trust signals: "⭐ 100+ 5-Star Google Reviews", "🏆 UK Champion", "📍 Chiswick & Ealing". Gold text on charcoal background, auto-scrolling marquee.

Wix equivalent: Strip with narrow height (40px) → Marquee widget OR Repeater with horizontal scroll animation. Alternative: static text bar with gold text.

Key CSS: background: #151515; color: #C9A84C; font-size: 0.75rem; letter-spacing: 0.1em; overflow: hidden; white-space: nowrap

BrandCard (Our Brands Section) Important

Description: 4-column grid of brand cards (Pura Nights, Pura Ladies, Wedding Dance, Private Lessons). Each: icon/emoji, H3, short description, "Learn More →" link.

Wix equivalent: Repeater in 4-column grid → each item: icon image + heading + paragraph + link text

Key CSS: background: #fff; border-radius: 16px; padding: 32px; box-shadow: 0 4px 20px rgba(0,0,0,0.06); transition: transform 0.3s

TestimonialCard Important

Description: Card with 5 gold stars, quote text in italics, student name, and "Google ⭐" badge. Used in carousel and grid layouts.

Wix equivalent: Slider widget (for carousel) or Repeater (for grid). Each slide: stars image + text + name. OR install Elfsight Google Reviews widget.

Key CSS: background: #fff; border-left: 4px solid #C9A84C; padding: 24px; border-radius: 12px; font-style: italic

ClassScheduleTable Critical

Description: Two side-by-side cards showing Monday (Chiswick) and Tuesday (Ealing) schedules. Each card: venue name, address, transport info, timetable rows with level + time.

Wix equivalent: 2-column layout → each column: Box with heading + repeating text rows. OR use Wix Table element.

Key CSS: background: #1e1e1e; color: #fff; border-radius: 16px; padding: 32px. Time text: color: #C9A84C; font-weight: 600

PricingCard Critical

Description: 3 pricing tiers (Bronze £40, Silver £55, Gold £70). "Most Popular" badge on Silver. Each card: price, feature list with checkmarks, CTA button.

Wix equivalent: Wix Pricing Plans app OR manual 3-column Repeater. Highlight card: gold border + "Most Popular" ribbon.

Key CSS: Popular card: border: 2px solid #C9A84C; transform: scale(1.05). Button: background: #C9A84C; color: #151515; border-radius: 8px

FAQAccordion Important

Description: Collapsible Q&A section. Question row with + icon, answer expands below. Used on nearly every page.

Wix equivalent: Wix FAQ app (built-in) or Accordion widget. Configure: single-expand mode, gold accent on active question.

Key CSS: border-bottom: 1px solid #e5e5e5; padding: 16px 0. Active question: color: #C9A84C; font-weight: 600

BlogPostCard Important

Description: Card with category badge (coloured pill), H3 title, excerpt (2 lines), reading time, "Read →" link. Used in Blog index grid and Related Posts sections.

Wix equivalent: Wix Blog app with custom layout. OR Repeater with: badge element + heading + paragraph + link.

Key CSS: background: #fff; border-radius: 16px; padding: 24px; border: 1px solid #eee. Badge: border-radius: 999px; padding: 2px 12px; font-size: 0.7rem

WhatsAppButton (Floating) Critical

Description: Fixed-position green circle button at bottom-right with WhatsApp icon. Always visible. Links to wa.me/447449482343.

Wix equivalent: Wix Chat widget (WhatsApp mode) OR custom button element with fixed position. Set in Wix: "Attach to screen" → bottom right.

Key CSS: position: fixed; bottom: 24px; right: 24px; width: 56px; height: 56px; background: #25D366; border-radius: 50%; z-index: 50

StickyMobileCTA Important

Description: Fixed bottom bar on mobile only. Contains "Book a Class" and "WhatsApp" buttons side by side. Appears after scrolling past hero.

Wix equivalent: Use Wix mobile editor → add fixed footer strip with two buttons. Only visible on mobile breakpoint.

Key CSS: position: fixed; bottom: 0; left: 0; right: 0; padding: 12px 16px; background: #151515; display: flex; gap: 8px; z-index: 40

ExitIntentPopup Important

Description: Lightbox popup triggered on exit intent (mouse leaving viewport). Contains offer text and CTA. Shows once per session.

Wix equivalent: Wix Lightbox → trigger: "On mouse out" or timed trigger. Set frequency: once per session. Include heading + CTA button.

EventCountdown Important

Description: Countdown timer showing days/hours/minutes/seconds to next Latin Friday event. Gold numbers on dark background.

Wix equivalent: Wix Countdown Clock widget. Set target date manually each month. Style: dark background, gold number text.

AuthorCard SEO

Description: Inline card in blog posts showing author photo, name "Melitta Siomos", title, and link to /about. Supports E-E-A-T signals.

Wix equivalent: Custom Box element with image + text stack. Reuse across all blog posts via Wix Blog author settings.

ReadingProgressBar SEO

Description: Thin gold bar at very top of page that fills left-to-right as user scrolls through blog post.

Wix equivalent: Requires Wix Velo (custom code). Add a thin div fixed to top, width driven by scroll percentage. OR skip — low priority for Wix.

RelatedPages SEO

Description: Grid of 3–6 internal link cards at bottom of every page. Each card: title + short description + arrow. Drives internal linking.

Wix equivalent: Repeater or manual Box grid. Each item: heading + paragraph + link. Update links per page.

CookieConsent Important

Description: Bottom-anchored banner with "Accept" and "Manage" buttons. First visit only.

Wix equivalent: Wix has built-in Cookie Consent Banner (Settings → Privacy & Cookies). Enable and customise text/colours.

D — Wix-Specific Notes

1. Use Wix Editor (Not Wix Studio)

Wix Editor provides maximum drag-and-drop flexibility and the widest app marketplace. Wix Studio is aimed at agencies and has a different workflow — avoid unless the developer specifically prefers it.

3. Font Setup

Go to Site Design → Text Themes and set:

  • Heading 1–2: Playfair Display (upload via "Upload Fonts" if not in Wix library)
  • Heading 3–6: Poppins 600
  • Paragraph: Poppins 400
  • Small / Labels: Montserrat 500

4. Mobile Optimisation

After building each page on desktop, switch to Mobile Editor and:

  • Reduce heading sizes (H1: 32px, H2: 24px)
  • Stack columns vertically
  • Ensure buttons are full-width and touch-friendly (min 48px height)
  • Hide decorative elements that clutter mobile view
  • Test sticky mobile CTA bar positioning

5. SEO Setup (Per Page)

For every page, go to Page Settings → SEO and set:

  • Page Title: Use the H1 + " | Melitta Siomos" (under 60 chars)
  • Meta Description: Unique description per page (under 160 chars)
  • URL Slug: Match exactly as listed in the page map above
  • Schema Markup: Add LocalBusiness JSON-LD to local pages (use Wix SEO → Advanced → Custom Code)

7. Colour Application in Wix

Go to Site Design → Colour Palette and set:

  • Colour 1 (Primary): #C9A84C (Gold)
  • Colour 2 (Secondary): #F2A07B (Peach)
  • Colour 3 (Dark): #151515 (Charcoal)
  • Colour 4 (Light): #FDFBF5 (Ivory)
  • Colour 5 (Accent): #CF6A3D (Terracotta)

Then use "Theme colours" throughout instead of custom hex codes for consistency.

8. Performance

  • Compress all images before upload (TinyPNG or Squoosh)
  • Use WebP format where possible
  • Limit custom fonts to the 3 specified (Playfair Display, Poppins, Montserrat)
  • Avoid excessive animations — use Wix built-in "Reveal" effects sparingly
