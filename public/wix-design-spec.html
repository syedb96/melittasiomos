E — Wix Implementation Notes

1. Use Standard Wix Editor (Not Wix Studio)

This spec is optimised for the standard Wix Editor.

2. Font Loading

Add Playfair Display, Poppins, and Montserrat via Site Design → Text Theme. All available in Wix's Google Fonts library.

3. Mobile Editor

Critical: After building each desktop page, switch to Mobile Editor and adjust:

  • Reduce font sizes by ~30%
  • Reduce section padding (80px → 48px)
  • Stack columns vertically
  • Make CTA buttons full-width
  • Hide decorative elements that clutter mobile

4. SEO Setup Per Page

FieldGuidance
Title Tag<60 chars with primary keyword + brand
Meta Description<160 chars with CTA language
H1One per page, includes primary keyword
URL SlugMatch page map paths exactly
Alt TextEvery image needs descriptive alt text
Canonicalhttps://www.puranights.com{path}

5. Domain Connection Checklist

  • Connect puranights.com as primary domain
  • SSL certificate (automatic with Wix)
  • Set www redirect (be consistent)
  • Submit sitemap to Google Search Console
  • Set up Google Analytics 4
  • Verify domain in Search Console

6. Performance Tips

  • Compress images (WebP, max 200KB each)
  • Use Wix's built-in lazy loading
  • Limit custom HTML embeds
  • Use Wix animations sparingly (1-2 per section)

G — Domain & Canonical Strategy

CRITICAL: If both melittasiomos.com and puranights.com are active, choose ONE primary domain and set up a 301 redirect from the other. Running both with overlapping content will split SEO equity and confuse Google. Recommended primary: melittasiomos.com (stronger personal brand authority). Set puranights.com to redirect to melittasiomos.com OR vice versa — but pick one and be consistent everywhere (Google Business Profile, social links, backlinks).
  • Set canonical URLs on every page in Wix (Settings → SEO → Canonical URL)
  • Update Google Business Profile to match the chosen primary domain
  • Update all social media bio links to use the primary domain
  • Submit the primary domain sitemap to Google Search Console
  • Request removal of the secondary domain's indexed pages once redirects are active
