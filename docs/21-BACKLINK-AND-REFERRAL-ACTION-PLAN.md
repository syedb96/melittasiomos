## 5. Cadence

- **Weekly Mon (15 min)**: 3 outreach emails from table above. Log status.
- **Weekly Sat (5 min)**: Send T7 review WhatsApp to last week's Latin Friday attendees.
- **Monthly 1st (30 min)**: GBP posts (3 across 3 profiles). Audit anchor text mix in `mem://`.
- **Quarterly**: Review backlinks via Ahrefs Webmaster Tools (free). Disavow only if obviously toxic.

## 6. Hard rules

1. Never buy links.
2. Never use PBNs / link farms / Web 2.0 spam.
3. Never repeat the same anchor text >3 times across the whole profile.
4. Always link to the **most relevant page**, not the homepage by default.
5. Always offer reciprocal value (mention the venue, tag them on social, send students to their bar).
6. Never fabricate reviews or testimonials.
7. Never claim press features that aren't real.
