## Image Specifications

| Property | Standard |
|----------|----------|
| Format | WebP (with JPG fallback) |
| Max width | 1920px |
| Hero images | 1920×1080 (16:9) |
| Card thumbnails | 800×600 (4:3) |
| Square portraits | 800×800 (1:1) |
| Blog featured | 1200×630 (OG-safe) |
| File naming | `{subject}-{location}-{context}.webp` |
| Alt text | Required. Descriptive. Include location/brand where natural. |
| Lazy loading | All images below the fold |

## Caption Tone

- Warm, personal, community-focused
- Example: "Tuesday night bachata at the Drayton Court — beginners welcome every week"
- NOT: "Image of people dancing" or "Stock photo of dance class"

## Current Placeholder Strategy

Until real photos are available:
- Generated images used as layout placeholders
- All stored in `src/assets/` with descriptive names
- Each placeholder has alt text describing intended replacement
- Wix Design Spec includes a media replacement checklist
