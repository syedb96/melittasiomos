## 1) Image specifications (Wix-ready)

| Property            | Standard                                                                 |
|---------------------|--------------------------------------------------------------------------|
| Primary format      | WebP (with JPG fallback for legacy browsers)                             |
| Max width           | 1920px (downscale anything larger before upload)                         |
| Hero / full-bleed   | 1920×1080 (16:9)                                                         |
| Editorial portrait  | 1200×1500 (4:5) — best for IG and Wix two-column blocks                  |
| Card thumbnail      | 800×600 (4:3)                                                            |
| Square portrait     | 800×800 (1:1)                                                            |
| Blog featured / OG  | 1200×630                                                                 |
| Mobile hero         | 1080×1350 (4:5) — vertical crop variant                                  |
| Compression target  | < 250KB hero, < 120KB cards, < 80KB thumbnails                           |
| Colour profile      | sRGB, embedded                                                           |
| File naming         | `{subject}-{location}-{context}.webp` (lowercase, hyphens, no spaces)    |
| Alt text            | Required. Descriptive. Include location/brand where natural.             |
| Lazy loading        | All images below the fold (`loading="lazy"`)                             |
| Focal point         | Set in Wix Media Manager so crops don't cut off faces                    |

## 2) Video specifications

| Property            | Standard                                                                 |
|---------------------|--------------------------------------------------------------------------|

| Wedding reel        | 1920×1080, 60–90s, MP4, < 20MB                                           |

## 4) Caption & alt-text tone

Warm, personal, community-focused. Always include place + context.

✅ "Tuesday night bachata at the Drayton Court — beginners welcome every week."
✅ "Melitta running a beginners drill at The George IV, Chiswick."
❌ "Image of people dancing."
❌ "Stock photo of dance class."

Alt text must:
- Describe what's actually in the frame (people / action / venue)
- Mention the brand or location when natural
- Stay under ~120 characters
- Never repeat the visible caption verbatim
