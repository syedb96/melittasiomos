# Reusable Section Templates — Wix Design System

> These are the repeatable visual blocks that create the "£100k feel".
> Each template is designed in Lovable and documented for Wix replication.

---

## Template 1: Hero Section (Dark Cinematic)

**Used on**: Homepage, Pura Nights, About, Wedding Dance, Beginners, Venue pages
**Wix element**: Full-width Strip + image/video background + overlay + text + buttons

| Property | Value |
|----------|-------|
| Height | 70-90vh |
| Background | Full-bleed image, dark overlay 60-70% opacity |
| Overlay gradient | `linear-gradient(135deg, hsl(0 0% 0% / 0.7), hsl(0 0% 0% / 0.4))` |
| Headline | H1, white, font-size 48-64px desktop / 32-40px mobile |
| Subhead | Text, white/80%, 18-20px |
| CTA buttons | Primary (gold gradient) + Secondary (outline white) |
| Trust badge | Optional stat strip below |
