## Cadence

- **Weekly (Mon)**: 3 outreach emails. Track in spreadsheet.
- **Monthly**: refresh GBP posts with the next Latin Friday.
- **Quarterly**: audit backlinks via Ahrefs/Ubersuggest free tier — disavow only if obviously toxic.

## Rules

1. Never buy links.
2. Never use directory dumps (Web 2.0 spam, PBNs).
3. Never repeat the same anchor text more than 3 times across the whole profile.
4. Always offer reciprocal value (mention the venue, tag them on social, send students to their bar).
5. Always link to the **most relevant page**, not the homepage by default.
