## Purpose

Each snippet is pre-formatted with the canonical URL and brand-correct anchor text.

## Outreach workflow (per partner)
1. Personal email from Melitta — reference one specific thing about their venue/site
2. Attach 1-paragraph brand summary + 2 high-res photos
3. Offer reciprocal: featured listing on `/partner-with-pura-nights` + social mention
4. Send the relevant snippet from above as ready-to-paste HTML
5. Track in CRM (Supabase `enquiries` table, subject = `Partnership / Venue Collaboration`)
6. Follow up at 7 days, 14 days, 30 days

## Anchor-text discipline
- Vary anchors — never use the same phrase twice
- 60% branded ("Pura Nights", "Melitta Siomos")
- 25% descriptive ("Salsa classes in West London", "Bachata UK Champion")
- 15% URL-only ("puranights.com")
- Never request "salsa classes London" exact-match — Google flags it

## Reciprocal listings
On `/partner-with-pura-nights` we list partners with logo + 1-line description + outbound link. This gives partners a live backlink in return — a fair exchange that makes the ask easier.
