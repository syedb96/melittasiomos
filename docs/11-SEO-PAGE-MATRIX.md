## Local SEO Pages (footer + cross-link only)
All local pages KEEP, indexable, self-canonical, and noindex only if duplicate-thin. Pattern:
- Title: `{Style} Classes {Area} — Pura Nights` (≤60 chars)
- Description: `Weekly {Style} classes serving {Area}. Beginner-friendly, no partner needed. Drop in from £10.`
- H1: `{Style} Classes in {Area}`
- Schema: LocalBusiness + Place + Event
- Required internal links: `/pura-nights`, nearest venue page, `/start-here`
