## 1. Sitemap status — ✅ CLEAN

`public/sitemap.xml` is auto-generated by `scripts/seo-qa.ts` (run `bun run seo:build`).

- Format: valid XML, `urlset` namespace, no HTML, no trailing slashes (except `/`), no query params.
- Host: 100% `https://www.puranights.com`.
- Excludes: `/online-classes` (legacy 301), `/admin/*`, `/login`, `/refer`, `/proof-centre`, `/all-pages-master`, `/shop/*`, `/size-guide`, `/shipping-returns`, `/lookbook*`, cancelled events.

## 2. robots.txt — ✅ CLEAN

```
User-agent: *
Allow: /
Disallow: /admin
Sitemap: https://www.puranights.com/sitemap.xml
```
Major bots (Googlebot, Bingbot, Twitterbot, facebookexternalhit, GPTBot, OAI-SearchBot) explicitly allowed. CSS/JS/images not blocked.

## 3. Canonical status — ✅ CONSISTENT

All `<SeoHead path="...">` resolve to `https://www.puranights.com{path}`. CI guard in `scripts/seo-qa.ts` warns if any source file references the apex host.

## 4. Event schema status — ✅ FIXED

- `Event` JSON-LD only emitted by `src/pages/EventInstance.tsx` (`/events/:slug`).
- Recurring pages guarded by `RECURRING_PAGES` in `scripts/seo-qa.ts`: `PuraNights`, `Schedule`, `BachataClassesChiswick`, `DanceClassesChiswick`, `SalsaClassesChiswick`, `SalsaClassesEaling`, `BachataClassesEaling`. Build fails if any of them re-introduce Event schema.
- Each single event has: `startDate`, `endDate`, `eventStatus`, `eventAttendanceMode`, `image`, `location`, `organizer`, `performer`, `offers` (with `availability`, `itemCondition`, `category`, `validFrom`, `validThrough`, `priceValidUntil`).
